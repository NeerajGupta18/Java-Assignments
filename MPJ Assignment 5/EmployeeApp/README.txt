=== EmployeeApp - Setup Instructions ===

1. Run db_setup.sql in MySQL to create the database and table.

2. Update DBConnection.java with your MySQL password.

3. Add mysql-connector-java-8.0.13.jar to the lib/ folder.

4. Import project into Eclipse as a Dynamic Web Project.

5. Deploy on Apache Tomcat and open:
   http://localhost:8080/EmployeeApp/index.jsp
