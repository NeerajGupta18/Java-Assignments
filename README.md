# Java Assignments

Java programming assignments completed as part of coursework at **MIT World
Peace University**, covering core object-oriented programming concepts
through progressively more complex exercises.

## Contents

| Assignment | Topic | Description |
|---|---|---|
| [MPJ Assignment 1](./MPJ%20Assignment%201) | Classes & Objects | `student_info.java` — basic class design, fields, and object instantiation |
| [MPJ Assignment 2](./MPJ%20Assignment%202) | Inheritance | `inheritance.java` — parent/child class relationships and method inheritance |
| [MPJ Assignment 3](./MPJ%20Assignment%203) | Method Overriding | `method_overriding_hillstations.java` — polymorphism via method overriding |
| [MPJ Assignment 4](./MPJ%20Assignment%204) | Exception Handling | `exception_handling_banking_system.java` — try/catch, custom exceptions in a banking-system context |
| [MPJ Assignment 5](./MPJ%20Assignment%205) | Multi-class Application | `EmployeeApp` — a larger mini project combining multiple OOP concepts into one application |

## Purpose

This repo tracks incremental coursework rather than a single production
project — each folder is a standalone assignment demonstrating a specific
Java/OOP concept, in the order they were taught. Assignment 5 (`EmployeeApp`)
is the most complete, combining concepts from the earlier assignments into a
single multi-class application.
